# simple_earring

Co-designed LED earring: RP2350A + external QSPI flash, a rechargeable 2032 coin
cell, and 45 SK6805-EC10 addressable RGB LEDs around the periphery and in an
interior octagon. Ø30.5mm teardrop, 4-layer, JLCPCB rules, all parts from LCSC.
There is an IMU, an ambient light sensor, USB-C charging, and a generated TPU
clip-on case.

The design is *generated*: edit `design.yaml` (shape, LED count, sizes) and
`scripts/circuit.py` (netlist), then rebuild.

**Status:** rev 1 was ordered and assembled and works — it lives in a separate
worktree at `~/pcb/simple_earring_shipped` (commit `43eadc1`). This tree is
rev 3 (LiPo, one-button BOOTSEL, WS2816C zones), routed with ultraroute to
0 DRC errors / 0 unconnected; gate 7 review still open. See `docs/PLAN.md` for the plan of record and the running
dashboard feed for the narrative.

## Pipeline

```
python3 build.py                # full: board -> place -> route -> drc -> render -> export
python3 build.py --to place     # stop after a stage (board|place|route|drc|render|export)
```

Stages (each is also runnable standalone from `scripts/`):

| stage  | script              | what it does                                        |
|--------|---------------------|-----------------------------------------------------|
| board  | `gen_board.py`      | netlist from `circuit.py` -> fresh 4-layer .kicad_pcb, outline, nets |
| place  | `place.py`          | LED ring, MCU cluster front, holder back, USB at edge |
| route  | `route.py`          | locked pre-routes + pours, then ultraroute for the rest, zone fills |
| drc    | `drc.py`            | kicad-cli DRC, parsed pass/fail report              |
| render | `render.py`         | renders, layer PNGs, GLB, and the `out/` dashboard  |
| export | `export.py`         | JLCPCB gerbers/drill + BOM/CPL from LCSC numbers    |

The KiCad project is `hw/earring/a/earring.kicad_*` (the Boardroom suite's
`hw/<board>/<variant>/` layout; `scripts/paths.py` owns the locations). Build products
land in `out/` (renders, dashboard, `drc.json`, `production/`, `jlcpcb/`).

## Boardroom suite

This is a Boardroom project (`~/Software/easy_pcb`): `design/status.json` is its
headline state, `.claude/skills/pcb-design/` the vendored skill, `pcbview.toml` the
viewer config. `compose/earring/` is Circuit Composer's view of the circuit
(generated by `scripts/export_compose.py`, build stage `compose`), and
`route/earring/recipe.json` is the ultraroute recipe behind the installed route.
Routing is ultraroute: the `route` stage runs the pinned `vendor/ultraroute`
(`git submodule update --init`; `scripts/route.sh` builds it, needs Rust) with that recipe.
Alongside the board pipeline: `gen_schematic.py` (readable schematic + PDF),
`gen_case.py` (TPU case STLs/STEP), `firmware/` (PlatformIO, arduino-pico), and
`tools/` (bench instruments — charge monitor, placement spot scanner).

## Dashboard

```
cd out && python3 -m http.server 8618 --bind 0.0.0.0
```

`out/index.html` is a reverse-chronological update feed over the live build
outputs: renders, the copper-layer stack viewer, the 3D board, the schematic,
the case preview and the bench pages. It is **generated by `scripts/render.py`**
(the `FEED` list at the top of that file) — hand edits to the served page are
wiped by the next build. `python3 scripts/render.py --index-only` rewrites just
the page.

## Sources of truth

- `design.yaml` — geometry + rules parameters
- `scripts/circuit.py` — components and nets (references `bom/parts.yaml`)
- `bom/parts.yaml` — every part with LCSC number + footprint
- `library/parts.pretty/` — local footprints (proven ones lifted from prior boards)
- `docs/PLAN.md` — plan of record: current state, open work, hard-won constraints

## Provenance

Footprints and circuit patterns reuse the proven `earring` (RP2040 + LGS4056H + USB-C)
and `rp2350-pendant` (RP2350 QFN-60, 1010 LED ring) projects.

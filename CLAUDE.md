# simple_earring

A PCB project in the Boardroom suite (Boardroom = `~/Software/easy_pcb`, Circuit Composer,
UltraRoute Studio), run with the `pcb-design` skill vendored in `.claude/skills/pcb-design/`
(never hand-edit that copy; `VENDORED_FROM` names the upstream commit). Load it for any board
work and follow its phases and gates. Start every session by reading the skill's `LESSONS.md`,
`design/status.json` and `docs/PLAN.md`.

- The board is generated, not hand-edited: edit `design.yaml`, `scripts/circuit.py` and
  `bom/parts.yaml`, then `python3 build.py` (stages in `README.md`).
- Layout: the KiCad project is `hw/earring/a/earring.kicad_*` (where Boardroom, Composer and
  Studio look); renders, the dashboard, DRC report and fab files are `out/`. `scripts/paths.py`
  owns both. KiCad paths are `${KIPRJMOD}/../../../library/...`.
- `compose/earring/` is Circuit Composer's view (circuit.json, composed.json), generated by
  `scripts/export_compose.py` (build stage `compose`). Don't edit it.
- Routing is ultraroute, run outside build.py; the installed route's recipe is
  `route/earring/recipe.json`. **build.py's `route` stage still runs freerouting and overwrites
  the routed board — never run a full build or the route stage unasked.** Never run freerouting
  unasked.
- Dashboard: `out/index.html`, generated by `scripts/render.py` (never hand-edit); served by
  `proj up simple_earring`.
- Update `design/status.json` (schema 1, Boardroom's `docs/shell-spec.md`) at every gate and
  route; router results go under `apps.studio.earring`.
- The ORDERED rev 1 is at `~/pcb/simple_earring_shipped` (commit 43eadc1, old `out/` layout).
- Heavy jobs (routing, full builds, renders) go through `~/.claude/bin/reserve`.
- When the user corrects you: read `~/.config/boardroom/config.toml`; if its `skill_upstream`
  exists on this machine, add the rule to that copy's `LESSONS.md`; otherwise add it to this
  project's copy.
